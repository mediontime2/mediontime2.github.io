MediOnTime 개인정보처리방침

최종 수정일: 2026년 8월 30일

MediOnTime(이하 "서비스")은 이용자의 개인정보 및 프라이버시를 매우 소중하게 생각하며, 관련 법령을 준수합니다. 본 개인정보처리방침은 서비스가 어떠한 정보를 수집하고 어떻게 처리하는지 설명합니다.

1. 개인정보의 수집 및 이용 목적

본 서비스는 사용자의 편리한 복약 관리 및 기기 간 동기화를 위해 Google OAuth 2.0 로그인을 제공합니다. 서비스는 서비스 운영 목적 외에 이용자의 개인정보를 제3자에게 제공하거나 상업적으로 활용하지 않습니다.

2. 수집하는 정보 항목 및 저장 위치

  • Google 계정 기본 프로필 (이메일, 이름, 프로필 사진): 사용자 식별 및 화면 내 프로필 표시에만 사용됩니다.
  • 복약 일정 및 기록 데이터: 약품 이름, 복약 시간, 복약 완료 여부 등의 정보는 서비스 제공자의 중앙 서버가 아닌, 이용자 본인의 개인 Google Drive 비공개 앱 폴더(appDataFolder)에만 안전하게 저장됩니다.

3. 제3자 데이터 공유 및 전송

MediOnTime은 사용자의 복약 데이터를 자체 데이터베이스나 외부 서버에 일체 전송하거나 보관하지 않습니다. 모든 데이터 전송은 사용자의 브라우저와 Google API 서버 간에만 암호화되어 직접 이루어집니다.

4. Google API 사용자 데이터 정책 준수

MediOnTime의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한된 사용 요구사항 포함)을 엄격히 준수합니다.

5. 개인정보의 파기 및 접근 권한 철회

이용자는 언제든지 Google 계정 설정(보안 - 타사 앱 연결 관리)에서 MediOnTime에 대한 접근 권한을 즉시 철회하고 데이터를 삭제할 수 있습니다.
