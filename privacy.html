MediOnTime Privacy Policy

Last updated: August 30, 2026 / 최종 수정일: 2026년 8월 30일

1. 개요 (Introduction)

MediOnTime(이하 "서비스")은 사용자의 개인정보와 프라이버시를 최우선으로 보호합니다. 본 방침은 서비스 이용 시 수집되는 최소한의 정보와 그 보호 방식을 설명합니다.

2. 수집하는 정보 (Information We Collect)

서비스는 복약 관리 및 데이터 동기화를 위해 Google OAuth 2.0 표준 인증을 통해 다음 정보에 접근합니다:

  • Google 프로필 정보: 이메일, 이름, 프로필 사진 (사용자 식별 및 프로필 표시 목적)
  • Google Drive 비공개 앱 폴더 (drive.appdata): 오직 사용자의 복약 목록, 복용 시간, 복용 기록 파일만 저장/동기화
🔒 데이터 저장 원칙: MediOnTime은 자체 중앙 데이터베이스나 외부 서버를 일체 운영하지 않으며, 모든 복약 데이터는 사용자 본인의 개인 Google Drive 비공개 폴더에만 안전하게 저장됩니다.

3. 정보의 이용 목적 및 제3자 제공 금지 (Data Use & Sharing)

  • 수집된 정보는 복약 알림 시간 계산 및 기기 간 동기화 목적으로만 사용됩니다.
  • 서비스는 어떠한 경우에도 사용자의 개인정보나 복약 데이터를 제3자에게 판매, 공유, 전송하지 않습니다.
  • Google API 사용은 Google API 서비스 사용자 데이터 정책을 엄격히 준수합니다.

4. 권한 철회 및 데이터 삭제 (Data Deletion)

사용자는 언제든지 Google 계정의 타사 앱 연결 관리에서 MediOnTime의 연결 권한을 즉시 철회할 수 있습니다. 권한 철회 시 Google Drive에 저장된 앱 데이터도 즉시 접근 불가 처리됩니다.

English Summary for Google OAuth Verification

MediOnTime is a smart medication management application designed with a privacy-first architecture.

  • Zero Central Storage: MediOnTime does not host any backend database or store user medical data on external servers.
  • Google Drive App Folder (drive.appdata scope): Used exclusively to store and synchronize user medication schedules and logs within the user's private Google Drive application folder.
  • Data Sharing: We never sell, share, or disclose user data to third parties.
  • Security: All communication takes place directly between the user's device and Google's secure APIs via HTTPS OAuth 2.0 flows.
